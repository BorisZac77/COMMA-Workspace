# Instrukcje repozytorium dla Codexa

Ten projekt korzysta z kanału współpracy ChatGPT ↔ GitHub ↔ Codex.

Przed rozpoczęciem każdej pracy:
1. Przeczytaj w całości `.ai/context.md`.
2. Przeczytaj w całości `.ai/task.md`.
3. Wykonaj kontrole wstępne opisane w kontekście.
4. Realizuj tylko bieżące zadanie i tylko w dozwolonym zakresie.
5. Po zakończeniu zawsze zaktualizuj `.ai/report.md` oraz `.ai/handoff.md`.
6. Nie wykonuj commit ani push, jeśli bieżące zadanie nie zezwala na nie jednoznacznie.
